# Sample API Responses

Sample JSON responses from the public TRMNL API used for development and testing.

## API URLs

**Single recipe:**
```
https://trmnl.com/recipes/243525.json
```

**All recipes by author/user:**
```
https://trmnl.com/recipes.json?user_id=4318
```
